# 1234 BEAT

철권 콤보 악보 연습기 · 1234 BEAT

콤보를 **리듬 게임 악보**처럼 만들어서, 버튼 누르는 타이밍을 연습하는 웹 도구입니다.
설치 없이 브라우저에서 바로 쓸 수 있습니다.

👉 **바로 쓰기: https://persona7799.github.io/1234beat/**

## 기능

- **기록 모드**: 콤보를 스틱·패드로 한 번 입력하면 실제 타이밍 그대로 악보가 됩니다.
- **연습 모드**: 카운트다운 뒤 노트가 내려오고, 입력마다 `JUST / GOOD / MISS`와 몇 프레임 빠르거나 늦었는지 알려줍니다.
- **시범 보기**: 악보를 소리와 노트로 재생합니다. 유튜브 영상을 연결하면 영상과 노트가 함께 재생됩니다.
- **철권식 표기**: 화살표 + 4점 버튼 아이콘으로 커맨드와 입력 이력을 보여줍니다.
- **공유**: 악보(와 시범 영상 설정)를 링크 하나로 공유합니다. 서버나 회원가입이 필요 없습니다.

## 사용 방법

1. 스틱이나 패드를 PC에 연결하고 페이지를 엽니다. 아무 버튼이나 누르면 컨트롤러가 인식됩니다.
2. **설정** 탭에서 1~4 버튼을 할당합니다.
3. **기록** 탭에서 콤보를 녹화하고, **연습** 탭에서 따라 칩니다.
4. **악보 편집** 탭에서 이름을 붙이고 **공유 링크 복사**로 공유합니다.

키보드로도 쓸 수 있습니다: `WASD`/방향키 = 방향, `U I J K` = 1 2 3 4

## 참고

- 이 도구는 컨트롤러 입력만 읽습니다. 게임 화면이나 게임 데이터는 건드리지 않습니다.
- 철권(TEKKEN)은 Bandai Namco Entertainment의 상표이며, 이 도구는 공식 도구가 아닌 팬 제작 연습 도구입니다.
